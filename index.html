Мое web-решение

Сайт развернут с использованием GitHub Actions и CI/CD.

Описание проекта

Это учебное web-решение для демонстрации автоматического тестирования и публикации сайта.

CI/CD

При отправке изменений в ветку main запускается тест. Если тест успешен, сайт публикуется через GitHub Pages.
